# 全員が裏切りそうなRPG

魔王討伐前夜の宿屋から始まる、短編のブラウザRPGです（日本語・PCブラウザ向け）。

**▶ プレイする：https://keda-commits.github.io/zenin-uragiri-rpg/**

公開中のバージョン：`v5`（タイトル画面の右下にも表示されます）

## 操作

- 移動：WASD／矢印キー／クリック　ダッシュ：Shift
- 調べる・話す：E／Z／クリック　会話を進める：Z／Enter／クリック
- メニュー：Tab／Esc（会話中も開けます）
- 詳しい操作は、ゲーム内のメニュー →「操作方法」を見てください。

セーブはブラウザに自動で保存されます。
